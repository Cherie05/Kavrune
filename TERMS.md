## Storage operations

Creating a USB, restoring an image or formatting a drive erases existing data on the selected target. Check the drive's model, size and identifying details before confirming, and keep an independent backup outside that drive. Cancellation or a failure can leave an incomplete installation or storage layout. Formatting and raw writing are not secure erasure.

Use images from a publisher you trust. Kavrune verifies written bytes; it does not certify an image's safety, license, authenticity or ability to boot on every computer. The operating system started from a USB has its own terms and can change the computer's disks if you choose to install it.
