# Support

Use the repository's bug report form for reproducible problems and the feature request form for suggestions. Search existing issues before opening a new one. Kavrune 0.1 is a development preview; community support is provided as maintainers are available, with no guaranteed response time or enterprise service agreement.

Include the app version, Linux distribution, image type, the stage that failed, and relevant redacted diagnostics. Remove passwords, personal paths, device serials, and private image names before sharing logs. A screenshot of an error is useful; a full disk image is usually unnecessary.

Use temporary files or a disposable virtual machine to reproduce storage problems. Back up important data before using physical USB media. Do not repeat a failed destructive operation on a drive containing data you need.

For suspected device protection bypasses, privilege escalation, malicious-image vulnerabilities, or other security problems, follow [SECURITY.md](SECURITY.md) instead of posting exploit details in a public issue.

For setup and usage, see [README.md](README.md). For contribution questions, see [CONTRIBUTING.md](CONTRIBUTING.md). The [release roadmap](docs/ROADMAP.md) describes features that are still planned.
